Kalkulator Biaya Angkutan Biomassa

Perhitungan biaya trucking berbasis formula workbook Rev08. Hasil dihitung langsung di browser dengan presisi penuh dan ditampilkan sebelum pajak, dengan tampilan yang disesuaikan ke tema warna PT PLN EPI.

MODEL BOK • PERMENHUB

Input Parameter

Pilih PLTU dan masukkan parameter pengiriman. Perhitungan diperbarui otomatis.

km
Acuan 50 km: tarif Rp/Ton.Km dihitung pada 50 km, kemudian dikalikan jarak aktual.
ton
%
Default Excel: 50% (Asumsi!C5).
%
Default Excel: 10% (Asumsi!C6).
Rp/ltr
Nilai awal mengikuti Rekap Interview Driver kolom J dan dapat diubah manual.
Rp/rit
Nilai awal mengikuti tarif penyeberangan pada model Excel berdasarkan kapasitas truk dan dapat diubah manual.
Ring 2 memakai tarif Rp/Ton.Km hasil perhitungan pada 100 km, sedangkan Ring 3 pada 300 km; tarif tersebut kemudian dikalikan dengan jarak aktual. Untuk jarak di atas Ring 3 (>300 km), tarif Rp/Ton.Km tetap memakai basis 300 km kemudian dikalikan jarak aktual. Untuk Ring 1, pengguna dapat memilih basis 50 km atau menghitung langsung sesuai jarak aktual. Load Factor dan Profit/Margin dapat diubah manual dengan default Excel masing-masing 50% dan 10%. Harga BBM otomatis mengikuti Rekap Interview Driver kolom J. Jika memakai penyeberangan, biaya penyeberangan juga dapat diinput manual.

Basis perhitungan: Rev08-FINAL-Kalkulator Tarif Trucking Biomassa ALL PLTU R1.xlsx. Metode ring: R1 basis 50 km/aktual, R2 basis 100 km, R3 basis 300 km, dan jarak di atas Ring 3 tetap menggunakan basis tarif 300 km. Load Factor, Profit/Margin, Harga BBM, dan Biaya Penyeberangan dapat disimulasikan sebagai input. Kalkulasi dilakukan lokal pada perangkat pengguna; angka tampilan dibulatkan, sedangkan mesin perhitungan menggunakan presisi penuh dari formula Excel.
